# Danmark – Sundhedsundervisning: Retslig Ramme og Historisk Kontekst (1970–2024)

## 1. Panorama Duńskiego Systemu Edukacji

### 1.1 Dane Podstawowe

| Parametr | Wartość |
|---|---|
| Kraj | Dania / Danmark (DK) |
| Populacja | ~5,9 miliona (2024) |
| Język urzędowy | Duński |
| System edukacji | **Zdecentralizowany** – Børne- og Undervisningsministeriet (Ministerstwo Edukacji) ustala cele; szkoły mają dużą autonomię |
| Obowiązek szkolny | 6–17 lat (folkeskole + rok szkoły ponadpodstawowej) |
| Børnehaveklasse | 1 rok (klasa 0; 6-latki) |
| Folkeskole | 9–10 lat (klasy 1–9/10; 7–16/17 lat) |
| Gymnasium | 3 lata (STX/HF/HTX/HHX; 16–19 lat) |
| Egzamin końcowy | Studentereksamen (STX) lub odpowiedniki |
| Organ curriculumowy | Børne- og Undervisningsministeriet + Styrelsen for Undervisning og Kvalitet (STUK) |

### 1.2 Kluczowa Specyfika Duńskiego Systemu

- **Brak odrębnego przedmiotu "Edukacja Zdrowotna"** – model zbliżony do szwedzkiego (transwersal)
- **"Sundheds- og seksualundervisning og familiekundskab"** = obowiązkowy **temat** (emne), nie przedmiot
- **Idræt** (Wychowanie fizyczne) = główny formalny nośnik treści zdrowotnych
- **Biologi** = treści zdrowotne w zakresie biologii człowieka
- **Samfundsfag** (Wiedza o społeczeństwie) = zdrowie publiczne, system zdrowotny
- **Reformy 2021–2023** = znaczące wzmocnienie edukacji seksualnej na wszystkich poziomach

## 2. Historia: Obowiązkowa Edukacja Seksualna od 1970 r.

### 2.1 Chronologia Historyczna

| Rok | Wydarzenie |
|---|---|
| **1970** | Dania wprowadza **obowiązkową edukację seksualną w folkeskole** – jako drugi kraj nordycki po Szwecji (1955) |
| 1970–2000 | Edukacja seksualna zintegrowana z biologią i społeczeństwem (emne); realizacja nierówna |
| 2001 | Nowa ustawa o folkeskole – formalizacja tematów obligatoryjnych (emner) |
| **2021** | Rząd duński przeznacza **15 milionów DKK** na wzmocnienie edukacji seksualnej; wzmocnienie curriculum |
| **2023** | **Nowelizacja** – obowiązkowa edukacja seksualna rozszerzona na **gymnasiet** (od roku szkolnego 2023/24) |
| 2024 | Kontynuacja reform; Sex og Samfund wzmacnia programy wsparcia nauczycieli |

> **Dania była DRUGIM krajem nordyckim** (po Szwecji) i jednym z pierwszych na świecie z obowiązkową edukacją seksualną (1970). Reforma 2023 rozszerzyła obowiązek na szkoły ponadpodstawowe (gymnasium).

### 2.2 Reforma 2023 – Rozszerzenie na Gymnasium

**Przed reformą**: Uczniowie gymnasium (16–19 lat) oficjalnie nie mieli obowiązkowej edukacji seksualnej – luka przez ponad 50 lat.

**Po reformie 2023**: Seksualundervisning obowiązkowa w **wszystkich programach gymnasium** (STX, HF, HTX, HHX), obejmując:
- Zgoda (samtykke)
- Granice osobiste
- Antykoncepcja
- Choroby przenoszone drogą płciową

## 4. Status Prawny "Sundheds- og seksualundervisning og familiekundskab"

### 4.1 Charakterystyka Prawna

**Typ regulacji:** Obligatoryjny **temat** (emne), nie obowiązkowy **przedmiot** (fag)

**Implikacje:**
- Brak własnej siatki godzin
- Brak wymogu minimalnej liczby godzin
- Dyrektor szkoły decyduje, w ramach których przedmiotów i w jakiej formie temat jest realizowany
- Brak oddzielnych stopni/ocen za ten temat
- *Skolelederen* (dyrektor) ponosi odpowiedzialność za realizację

**Trzy przedziały wiekowe (trinforløb):**
1. Børnehaveklasse – 3. klasse (6–10 lat)
2. 4.–6. klasse (10–12 lat)
3. **7.–9. klasse (13–16 lat)** ← fokus projektu

**Dwa obszary kompetencji (kompetenceområder):**
1. **Sundhed og trivsel** (Zdrowie i dobrostan)
2. **Køn, krop og seksualitet** (Płeć, ciało i seksualność)

## 5. System Zdrowia Szkolnego

### 5.1 Sundhedspleje (Opieka Zdrowotna w Szkołach)

Dania ma system **sundhedspleje** (dosłownie: pielęgnacja zdrowia):
- Szkolne pielęgniarki (*sundhedsplejersker*) regularnie odwiedzają szkoły
- Systematyczne przeglądy zdrowotne uczniów (waga, wzrost, wzrok, słuch)
- Rozmowy zdrowotne z uczniami (1:1, poufne)
- Nie wszystkie szkoły mają pełną obsadę – problem w małych szkołach

### 5.2 Brak Odpowiednika Ungdomsmottagning

W odróżnieniu od Szwecji i Finlandii, Dania **nie ma** sieci dedykowanych klinik zdrowia młodzieży porównywalnych z szwedzką *ungdomsmottagning*. Usługi zdrowotne dla młodzieży dostępne przez:
- Lekarza rodzinnego (gratis w systemie NHS)
- Sundhedspleje
- Planowanie rodziny przez lekarza
