## 1. Suomen Koulutusjärjestelmän Yleiskuva / Overview of the Finnish Education System

### 1.1 Perustiedot / Basic Data

| Parametri / Parameter | Arvo / Value |
|---|---|
| Maa / Country | Suomi / Finland (FI) |
| Väestö / Population | ~5,6 miljoonaa / ~5.6 million (2024) |
| Viralliset kielet / Official languages | Suomi + ruotsi / Finnish + Swedish |
| Koulutusjärjestelmä / Education system | **Hajautettu + kansallinen opetussuunnitelma** – Opetushallitus vahvistaa valtakunnalliset perusteet; kunnat ja koulut laativat omat opetussuunnitelmansa |

| Opetussuunnitelmaviranomainen | **Opetushallitus (OPH) / EDUFI** |

### 1.2 Erityispiirteet / Key Features

Suomen koulutusjärjestelmä on kansainvälisesti tunnettu:
- **Tasa-arvo** – ei yksityiskouluja perusopetuksessa; kaikille samat mahdollisuudet
- **Opettajien autonomia** – opettajat voivat vapaasti valita opetusmenetelmät
- **Ei standarditestejä** peruskoulussa – vain kansalliset arviointiuraukset (ja ylioppilaskoe lukiossa)
- **Paikallinen opetussuunnitelma** – kunnat ja koulut räätälöivät opetuksen kansallisten perusteiden pohjalta
- **PISA-menestys** – Suomi on ollut yksi maailman parhaiden koulujärjestelmien joukossa

## 4. Terveystieto Koulutusjärjestelmässä / Health Education in the System

### 4.1 Terveystieto Peruskoulussa (vuosiluokat 7–9)

| Ominaisuus | Arvo |
|---|---|
| Luokka | 7.–9. vuosiluokka (ikä 13–16) |
| Pakollisuus | **Pakollinen oppiaine kaikille** |
| Opetuksen laajuus | Vaihtelee kunnittain (~38–76 h / 3 vuotta yhteensä) |
| Vuosiluokat 1–6 | Terveysasiat integroitu ympäristöoppiin (ei itsenäistä oppiainetta) |
| Arviointi | Ei standardikoetta; opettajan oma arviointi + koulun kriteerit |
| Opettajan kelpoisuus | Maisterin tutkinto + terveystiedon aineopinnot (60 op) + pedagogiset opinnot (60 op) |

### 4.2 Terveystieto Lukiossa (Lukio)

| Ominaisuus | Arvo |
|---|---|
| Oppilaitos | Lukio (yleissivistävä, ikä 16–19) |
| Pakollisuus | **Pakollinen oppiaine** – 3 pakollista moduulia (TE1, TE2, TE3) |
| Valinnainen | Koulut voivat tarjota lisämoduuleja |
| Ylioppilastutkinto | Terveystieto voi olla **ylioppilaskoeaine** (valinnainen) |
| Opetussuunnitelma | Lukion OPS 2019, käyttöön 2021 |

### 4.3 Terveystieto Ammatillisessa Koulutuksessa

Oppivelvollisuuden laajentamisen myötä (2021) ammatillisessa koulutuksessa on myös terveystiedon sisältöjä, osin integroituina "Yhteisten tutkinnon osien" (YTO) pakollisiin opintoihin.

## 5. Keskeiset Periaatteet ja Filosofia

### 5.1 Terveysosaaminen (Health Literacy) – Ydinkonsepti

Suomalainen terveystieto rakentuu **terveysosaamisen** (health literacy) käsitteen ympärille:

> *"Terveysosaaminen on terveyteen liittyvien tietojen, taitojen, asenteiden ja toimintavalmiuksien kokonaisuus. Se sisältää kyvyn hankkia, ymmärtää, arvioida ja hyödyntää terveystietoa sekä tehdä terveydelle myönteisiä valintoja."*

Terveysosaaminen = tiedot + taidot + asenteet + eettinen vastuu + kriittinen ajattelu

### 5.2 Arvioinnin Etiikka (Ethics of Assessment)

Suomalainen opetussuunnitelma määrittelee selkeästi:

> **"Arviointi ei saa kohdistua oppilaan henkilökohtaisiin arvoihin, asenteisiin, temperamenttiin tai terveystottumuksiin."**

Tämä tarkoittaa, että oppilaan **henkilökohtaisia terveysvalintoja ei arvioida** – arvioidaan ainoastaan terveysosaaminen (kyky ymmärtää, analysoida ja kriittisesti arvioida terveyteen liittyviä ilmiöitä).

Tämä periaate erottaa Suomen mallin monista muista Euroopan maista.
